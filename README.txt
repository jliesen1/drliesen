Dr. Joseph Liesen website — upload instructions

Files to place in the TOP LEVEL (root) of your existing GitHub repository:
  index.html
  portrait.webp

In VS Code:
1. Open the local folder connected to your existing Cloudflare website (cds201a).
2. Replace the existing index.html with this index.html.
3. Add portrait.webp beside index.html (not in another folder).
4. Save changes, enter a descriptive commit message, click Commit, and Sync Changes.
5. When Cloudflare finishes deploying, refresh https://drliesen.com/.

This is a static website. No extra extensions, frameworks, or packages are needed.
The portrait is an optimized copy of the photograph you provided.

Tip: Keep README.txt on your local computer if you prefer. It is not required for the webpage.
